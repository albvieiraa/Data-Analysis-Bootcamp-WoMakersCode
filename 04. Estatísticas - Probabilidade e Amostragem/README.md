# Módulo: Estatísticas e Probabilidades

Analisar as características da força de trabalho nos estados brasileiros.

## 📝 Atividades Realizadas
- Limpeza, transformações e renomeação de colunas
- Estatística descritiva das variáveis
- Cálculos de probabilidades
- Densidade de probabilidade
- Cálculo da média, variância e desvio padrão
- Histograma de distribuição normal

## 🛠️ Ferramentas e Bibliotecas Utilizadas
- Python
- Pandas, Numpy
- Matplotlib, Seaborn
- scipy.stats

## 🗂️ Estrutura
- `notebook.ipynb`: Notebook com o código e a resolução dos desafios.
- `README.md`: Este arquivo com os detalhes do módulo.
