# Módulo: Classificação e Regressão

Realizar análises, correlações e regressões dos datasets 'iris' e 'load_digits'

## 📝 Atividades Realizadas
- Limpeza, transformações e renomeação de colunas
- Estatística descritiva das variáveis
- Plotagem de histogramas e boxplots
- Matriz de Correlação e de Confusão para os modelos de Regressão logística

## 🛠️ Ferramentas e Bibliotecas Utilizadas
- Python
- Pandas, Numpy
- Matplotlib, Seaborn
- scipy.stats, statsmodels.api
- sklearn.preprocessing, sklearn.metrics

## 🗂️ Estrutura
- `notebook.ipynb`: Notebook com o código e a resolução dos desafios.
- `README.md`: Este arquivo com os detalhes do módulo.
