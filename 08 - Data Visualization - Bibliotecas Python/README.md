# Módulo: Data Visualization

Utilizar diferentes bibliotecas para criar visualizações

## 📝 Atividades Realizadas
- Carregamento do dataset
- Gráficos de histograma, dispersão e de barras (interativo)
- Gráficos para séries temporais (linha, decomposição sazonal)

## 🛠️ Ferramentas e Bibliotecas Utilizadas
- Python
- Pandas, Numpy
- Matplotlib, Seaborn, plotly.express
- Statsmodels.tsa.seasonal, statsmodels.tsa.stattools

## 🗂️ Estrutura
- `notebook.ipynb`: Notebook com o código e a resolução dos desafios.
- `README.md`: Este arquivo com os detalhes do módulo.
