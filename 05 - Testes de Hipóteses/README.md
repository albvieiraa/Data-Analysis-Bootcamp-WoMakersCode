# Módulo: Testes de Hipótese

Realizar Testes A/B e testes de hipótese com os dados das doenças cardiácas de um dataset de pacientes.

## 📝 Atividades Realizadas
- Limpeza, transformações e renomeação de colunas
- Estatística descritiva das variáveis
- Cálculos de nível de confiança (1 - alfa) e de significância (alfa)
- Testes t-studant e p-valor para verificar as hipóteses

## 🛠️ Ferramentas e Bibliotecas Utilizadas
- Python
- Pandas, Numpy
- Matplotlib, Seaborn
- scipy.stats

## 🗂️ Estrutura
- `notebook.ipynb`: Notebook com o código e a resolução dos desafios.
- `README.md`: Este arquivo com os detalhes do módulo.
