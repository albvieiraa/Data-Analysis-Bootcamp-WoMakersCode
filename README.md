# Bootcamp Data Analysis - WomakersCode

Este repositório contém os desafios individuais e projetos realizados durante o Bootcamp **Data Analysis** da [WomakersCode](https://womakerscode.org/), abordando conceitos fundamentais e ferramentas essenciais para análise de dados.

## 🚀 Objetivo do Bootcamp
O Bootcamp tem como foco capacitar mulheres para se tornarem analistas de dados, explorando temas como estatística, banco de dados, visualização de dados, e ferramentas populares como Python, Google Sheets e bibliotecas para machine learning.

## 📂 Estrutura do Repositório
Cada pasta corresponde a um módulo do Bootcamp e contém:
- Notebooks do **Google Colab** com o código e os desafios realizados.
- Um arquivo `README.md` detalhando o conteúdo do módulo.

### Conteúdo
1. **Python para Dados**: Introdução à linguagem Python para análise de dados.
2. **Banco de Dados**: Manipulação de bases de dados e consultas SQL.
3. **Estatísticas e Frequências**: Conceitos básicos de estatística descritiva.
4. **Estatísticas - Probabilidade e Amostragem**: Introdução à probabilidade e técnicas de amostragem.
5. **Estatística - Testes de Hipóteses**: Aplicação de testes estatísticos para validação de hipóteses.
6. **Estatística - Correlação e Regressão**: Análise de relações entre variáveis.
7. **Regressão Logística - Modelos de Classificação**: Implementação de modelos de classificação com Python.
8. **Data Visualization - Bibliotecas Python**: Criação de gráficos e visualizações interativas.
9. **Data Analysis - Google Sheets**: Técnicas de análise de dados utilizando Google Sheets.

## 🛠️ Tecnologias e Ferramentas Utilizadas
- Python (Google Colab)
- Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn
- SQL
- Google Sheets
