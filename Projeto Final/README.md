# Desafio Final: Previsão de Bullying - Squad Hedy Lamar

Desenvolver um modelo de previsão de bullying utilizando um dataset da Global School-Based Student Health Survey (GSHS).

## 📝 Atividades Realizadas
- Limpeza e análise incial dos dados para entender o dataset
- Transformação das variáveis categóricas em valores binários
- Análise descritiva das variáveis
- Plotagem de gráficos para melhor interpretação
- Calculo do valor de contingência (Cramér's V)
- Construção e validação do Modelo de Regressão

## 🛠️ Ferramentas e Bibliotecas Utilizadas
- Python
- Pandas, Numpy
- Matplotlib, Seaborn
- scipy.stats, statsmodels.api
- sklearn.preprocessing, sklearn.metrics

## 🗂️ Estrutura
- `notebook.ipynb`: Notebook com o código e a resolução dos desafios.
- `README.md`: Este arquivo com os detalhes do módulo.
